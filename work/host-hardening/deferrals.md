# Deferrals — host-hardening

- **Raised (code-review r2, MEDIUM):** a path segment longer than the filesystem name limit (e.g. `GET /sprites/` + 5000×`a`, or `GET /` + 5000×`a`) still returns 500: `resolve()` succeeds but `is_file()` raises `OSError: [Errno 63] File name too long` outside the try in `server/main.py`. **Deferred:** no player or client produces such a URL, and fixing it now would force the final (3rd) review round for a non-user-facing edge. **Lands in:** next unit that touches `server/main.py`: catch `OSError` around the `is_file()` checks (or stat inside `_resolve_inside`) and add a long-name test.
- **Raised (code-review r1+r2, LOW, no action):** curl exits other than 7 (missing curl, `PORT=abc`) report "port in use"; a signal between `cloudflared &` and `tunnel_pid=$!` could orphan a tunnel; a failed restart blocks the poll loop up to 30 s; "Terminated: 15" printed on shutdown; `HEAD /sprites/<file>` returns 405; `kill -0` on a reaped tunnel PID could in theory hit a reused PID; the port can be grabbed during the build after the pre-check.
