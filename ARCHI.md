# Architecture

_A snapshot of what the codebase IS — regenerated by `/init` and `/compact`, never hand-groomed._

## Stack

Python 3.12 (engine, Streamlit app, FastAPI backend, data pipeline) + React 18 / Vite / Tailwind v4 (multiplayer client in `client/`). pytest for tests, ruff (0.16 defaults, no project config) for lint. No database: format rosters are checked-in JSON, sessions are in-memory. Live drafts are hosted from the Owner's machine via `host.sh` (one uvicorn serving API + built client, exposed by a cloudflared quick tunnel); `render.yaml` (two services: `pokemon-draft-api` uvicorn backend, `pokemon-draft-web` static client) remains as a fallback.

## Layout

- `engine/` — the draft rules, the single source of truth both UIs wrap. `pool.py` (`DraftPool`: load a format's JSON via `config/draft_config.yaml`, `generate_pool` random / vr_weighted / stratified, `remove`/`restore`, `tier_cost`), `validator.py` (`Validator.check` → `PickResult`; ordered checks: in pool → roster full → budget, first failure wins), `draft_state.py` (`DraftState`: snake|linear order as a pure function of picks made, `pick`, one-step `undo`, `export`).
- `app/streamlit_app.py` — Mode A: single-screen draft, host clicks for every team; writes `exports/draft_<format>_<ts>.json`. Not deployed.
- `server/` — Mode B backend. `session_manager.py` (in-memory `Session`/`SessionManager`, `SessionError` subclasses → HTTP via one exception handler; per-room budget/roster overrides by mutating `pool._config` before building `DraftState`), `models.py` (pydantic request/message shapes), `main.py` (REST `/session…`, `/health`; WebSockets `/session/{id}/lobby` and `/session/{id}/draft?team_name=`; `ConnectionManager` broadcast drops dead sockets; `/sprites` static route and the client catch-all serve files with SPA fallback to `index.html`, traversal-guarded, and return 404 JSON for unmatched `session`/`sprites`/`health` paths; static routes and `/health` accept HEAD).
- `client/` — Mode B frontend. `src/pages/` Setup → Lobby → Draft; `src/hooks/useLobbySocket`/`useDraftSocket` (auto-reconnect, reload board); `src/identity.js` keeps the player's team per room in `localStorage` — Draft fetches the session first and offers a "Rejoin as…" picker when the stored team is missing or stale, and a started Lobby links there; `src/api.js` derives REST/WS URLs from `VITE_API_URL` (unset in dev → same-origin via the Vite proxy in `vite.config.js`). `scripts/e2e-drive.mjs` is the real-Chrome driver behind the `drive-multiplayer-draft` skill.
- `config/draft_config.yaml` — budget, roster size, team limits, default pool size, per-tier costs, format → data file map. Shared by both modes.
- `data/` — `aaa_pokemon.json`, `pokebilities_pokemon.json` (pipeline output, checked in); `data/raw/*.html` cached Smogon pages.
- `scripts/` — two things share this folder: the **data pipeline** (`scrape_smogon.py` → `normalize_names.py` → `build_pool.py` → `fetch_sprites.py`, plus `fetch_ps_nfe.py`, each with a sibling `test_*.py`) and the **harness** shell layer (`gate.sh`, `worktree.sh`, `agent-exec.sh`, `codex-review.sh`, `fan-exec.sh`, `release.sh`, `state.sh`, `archi-fresh.sh`). `scripts/gate.d/` holds this repo's gate hooks: `pytest.sh` (whole-repo `python3 -m pytest`) and `client-build.sh` (`npm ci` if needed, then `vite build`).
- `sprites/` — generated by `fetch_sprites.py`, gitignored; the guarded `/sprites/{name:path}` route serves files when present and returns 404 JSON when missing.
- Harness: `CLAUDE.md` / `ARCHI.md` / `PLAN.md` (hot tier), `AGENTS.md` (implementer contract), `config.yaml`, `skills/` (loop stages + `drive-multiplayer-draft`; exposed via the `.claude/skills → ../skills` symlink), `.claude/agents/` (read-only reviewers), `profiles/`, `knowledge/` (cold, empty), `work/<slug>/`, `VERSION` / `CHANGELOG.md` (CalVer, written only by `release.sh`).

## Entry points

- `./host.sh` — draft night: checks that the port is free, builds the client same-origin (`VITE_API_URL=` overrides `client/.env.production`), re-checks the port before launch, runs uvicorn on 127.0.0.1:$PORT (8000) under `caffeinate`, opens a cloudflared quick tunnel (`TUNNEL=cloudflared|none`), and restarts a dropped tunnel with a new share link; Ctrl-C stops only its own processes.
- `./dev.sh` — local multiplayer: uvicorn on :8000 + Vite on :5173 (installs client deps on first run).
- `streamlit run app/streamlit_app.py` — Mode A on :8501.
- `uvicorn server.main:app` — backend alone; `npm --prefix client run build` — client production build.
- `python3 -m pytest -q` — all Python tests (engine, server, pipeline); `npm --prefix client run e2e:browser` — real-browser drive (needs a running stack + Chrome).
- `scripts/gate.sh` — ruff, shellcheck, client build, pytest. Exit 0 = pass. The loop: `/1-plan` → `/2-implement` → `/3-review` → `/4-release` → `/5-retro`.

## Conventions

- **Engine rules change only in `engine/`.** Both UIs and the server wrap it; never re-implement budget/turn/undo logic in `server/` or `client/`.
- **Run pytest as `python3 -m pytest`**, not bare `pytest` — the `-m` form puts the repo root on `sys.path` so `import engine` / `import server` resolve.
- **Pipeline tests import their script as a top-level module** (`import fetch_sprites as m`) and patch by that module path (`patch("fetch_sprites.requests.get")`).
- **Undo is one step only** (`DraftState` keeps a single undo record); multiplayer undo is host-only (slot 1). Join order = draft order.
- **Client dev is same-origin through the Vite proxy**; only production sets `VITE_API_URL`, which is baked in at build time.
- **`data/*.json` is pipeline output** — regenerate via `scripts/`, don't hand-edit; tier strings must exist in `tier_costs` or `DraftPool.tier_cost` raises.
- ruff runs with no project config, so its rule set is whatever the installed ruff version defaults to; a ruff upgrade can redden the gate with no code change.
